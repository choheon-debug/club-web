# 우리 모임 (웹앱)

총무 한 사람이 휴대폰으로 여러 모임의 일정·참석·회비를 관리하는 웹앱입니다. 로그인이 없고, 자료는 총무 휴대폰 안에만 저장됩니다. (미용실 예약 웹앱을 바탕으로 만들었습니다.)

- 모임 여러 개 (동창회, 산악회 등), 주기: 매월 ○째 ○요일 / ○주마다 / 직접 정함
- 모임 날: 회원별 참석·회비 체크 → 회비 장부에 자동 기록, 모임 완료 시 다음 모임 날짜 자동 계산
- 회비 방식: 모임 때마다 / 매월 / 매년, 특별회비(경조사), 수입·지출 장부, 잔액
- 미납 안내 문자(계좌번호 포함), 모임 안내 단체 문자, 카톡용 결산 보고 복사
- 휴대폰 캘린더 등록(.ics), 백업 파일 저장·불러오기 (총무 넘기기)

## 파일
- `index.html`: 앱 전체
- `sw.js`: 오프라인용 서비스 워커. 앱을 고치면 `VERSION`을 올려야 휴대폰에 새 버전이 퍼짐
- `manifest.webmanifest`, `icons/`: 홈 화면 아이콘
- `gowun-batang-bold.woff2`: 고운바탕 글꼴 (SIL Open Font License)
